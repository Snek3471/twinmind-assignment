## Design Context

Register: **product**. Full strategic + visual specs at `../PRODUCT.md` and `../DESIGN.md` (project root, one level up).

North Star: "The Night Operator's Console" — calm, glanceable copilot UI, not a SaaS dashboard.

Key rules (see DESIGN.md for full detail):
- Electric Blue (#3b82f6) = the only color meaning "actionable"
- Signal Orange (#f58133) = the only color meaning "live right now"
- No display/hero type scale — 20px is the ceiling
- Flat by default; shadows/blur reserved for the Settings overlay only
